# Ejercicio 008 - UPDATE para fútbol sala

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `jugadores_futsal` para almacenar información deportiva de jugadores.
- Se agregaron restricciones `PRIMARY KEY`, `NOT NULL`, `DEFAULT`, `ENUM` y `CHECK`.
- Se insertaron ocho jugadores con estadísticas diferentes.
- Las consultas fueron diseñadas para practicar modificaciones mediante `UPDATE`.
- Se utilizaron actualizaciones sobre valores numéricos, cambios de estado y modificaciones de información del jugador.
- La última consulta permite validar los cambios realizados después de ejecutar los UPDATE.
