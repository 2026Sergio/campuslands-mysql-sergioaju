# Resolución Ejercicio 003 (Básico) - Primary Key Inventario Skins

**Estudiante:** Allison Vargas  
**Nivel:** Básico Inicial  

## Descripción
Uso de `PRIMARY KEY AUTO_INCREMENT` en MySQL para la gestión de inventario de skins. Garantiza que cada elemento posea una clave única irremplazable.

## Estructura
- `ddl/schema.sql`: Creación de la tabla `skins_basico` definiendo la clave primaria.
- `dml/inserts.sql`: Carga de 8 registros de skins.
- `dql/consultas.sql`: 5 consultas con filtrado por ID, agrupaciones por rareza y estados.
