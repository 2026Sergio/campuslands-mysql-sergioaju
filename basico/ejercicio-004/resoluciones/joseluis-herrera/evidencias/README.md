# Ejercicio04

# Taller de motos - SQL

# Descripcion 
En este ejercicio se realizó la creación de una base de datos para un taller de motocicletas. Incluye el diseño del esquema relacional (DDL) y la inserción de registros iniciales (DML) con información relevante sobre las motocicletas disponibles en el inventario. La tabla principal cuenta con un identificador autoincremental para una gestión eficiente de los registros.
