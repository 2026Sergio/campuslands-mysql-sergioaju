# Ejercicio 004 - INSERT

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó una tabla llamada `motos`.
- El ejercicio está enfocado en el uso de la sentencia `INSERT`, por lo que se agregaron ocho registros realistas.
- Se incluyeron restricciones `PRIMARY KEY`, `NOT NULL`, `CHECK` y `DEFAULT` para garantizar la integridad de los datos.
