# Resolución Ejercicio 002 (Básico) - Tipos de Datos Battle Royale

**Estudiante:** Allison Vargas  
**Nivel:** Básico Inicial  

## Descripción
Uso adecuado de tipos de datos en MySQL (`DECIMAL`, `INT`, `DATETIME`, `BOOLEAN`, `ENUM`) para registrar estadísticas y configuraciones de cuenta en un juego Battle Royale.

## Estructura
- `ddl/schema.sql`: Creación de la tabla `estadisticas_br` con validaciones `CHECK` y valores predeterminados.
- `dml/inserts.sql`: Inserción de 8 registros de prueba.
- `dql/consultas.sql`: 5 consultas analíticas enfocadas en leaderboards, promedios y filtros.
