# Ejercicio 002 - Tipos de datos

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó una única tabla llamada `ranking_battle_royale`.
- Se emplearon distintos tipos de datos de MySQL como `INT`, `TINYINT`, `VARCHAR`, `DECIMAL`, `BOOLEAN`, `ENUM`, `DATE` y `DATETIME`.
- Se agregaron restricciones mediante `CHECK`, `NOT NULL`, `DEFAULT` y `UNIQUE` para garantizar la integridad de los datos.
