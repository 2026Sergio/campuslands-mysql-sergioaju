# Ejercicio 006 - WHERE para autos hiperdeportivos

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó la tabla `autos_hiperdeportivos` para almacenar la información de los vehículos.
- Se agregaron restricciones `PRIMARY KEY`, `NOT NULL`, `DEFAULT`, `ENUM` y `CHECK` para asegurar la integridad de los datos.
- Se insertaron ocho registros con información realista de fabricantes reconocidos.
- Las consultas fueron diseñadas para practicar el uso de `WHERE` mediante igualdad, comparaciones, rangos y filtros sobre diferentes columnas.
