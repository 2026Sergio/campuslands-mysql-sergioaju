# Ejercicio 001 - CREATE TABLE

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones tomadas

- Se creó una única tabla llamada `equipos`, del ejercicio es de nivel básico.
- Se utilizaron restricciones como `PRIMARY KEY`, `UNIQUE`, `NOT NULL`, `DEFAULT` y `CHECK`.
- Se insertaron cinco registros para poder realizar consultas de filtrado, agrupación, ordenamiento y cálculos.
