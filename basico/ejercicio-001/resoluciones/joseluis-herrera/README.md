## Ejercicio 01

# Explicacion 
Se diseñó una tabla para registrar el rendimiento de un equipo en un juego de tipo MOBA, estructurándola con datos esenciales. Posteriormente, se realizaron inserciones de prueba con registros de distintos equipos y se aplicaron filtros para ordenar los resultados de mayor a menor rendimiento, además de aislar a aquellos con más de cuatro victorias.
