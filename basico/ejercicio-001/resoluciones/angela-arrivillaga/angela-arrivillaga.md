# ejercicio 001 - torneo moba

solucion del primer ejercicio sobre la tabla de un torneo de esports.

## archivos
- `ddl/schema.sql`: crea la base de datos y la tabla.
- `dml/inserts.sql`: agrega 9 equipos de prueba.
- `dql/consultas.sql`: hace 5 consultas sencillas para ver promedios, tops y filtros.

## como ejecutarlo
1. ejecutar primero `ddl/schema.sql`
2. luego ejecutar `dml/inserts.sql`
3. de ultimo probar `dql/consultas.sql`
