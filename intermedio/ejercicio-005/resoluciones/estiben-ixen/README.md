# README - Ejercicio 005 | Subconsultas

## Descripción

Este proyecto implementa una base de datos en **MySQL** para gestionar los servicios de un taller mecánico de motos. La solución utiliza **subconsultas** para comparar registros con valores calculados y generar reportes orientados al análisis de la información.

## Archivos

* **schema.sql:** creación de la base de datos y la tabla.
* **inserts.sql:** inserción de registros de prueba.
* **consultas.sql:** consultas utilizando subconsultas.

## Objetivo

Aplicar **subconsultas** para resolver consultas que dependan de resultados obtenidos previamente, permitiendo comparar costos, identificar valores máximos, mínimos, promedios y realizar filtros dinámicos.

## Competencias desarrolladas

* Diseño de tablas en MySQL.
* Uso de subconsultas en la cláusula **WHERE**.
* Aplicación de funciones de agregación como **AVG()**, **MAX()**, **MIN()** y **COUNT()**.
* Elaboración de consultas para el análisis de información del taller.
* Organización de scripts SQL siguiendo buenas prácticas.

## Ejecución

1. Ejecutar `schema.sql`.
2. Ejecutar `inserts.sql`.
3. Ejecutar `consultas.sql`.

## Resultado esperado

La solución debe ejecutarse correctamente en **MySQL** y generar consultas funcionales que demuestren el uso adecuado de **subconsultas** en un escenario de nivel intermedio, facilitando el análisis de costos y servicios registrados.
