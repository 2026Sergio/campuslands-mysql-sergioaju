# Ejercicio-05

# Explicacion 
En el siguiente ejercicio se realizo la practica de subconsultas.
Se creo una base de datos para un taller junto a 2 tablas donde se crearon una tabla de clientes y una de motos, cada tabla cuenta con sus propios datos 
ademas de eso se hizo una conexion donde se agrego una llave foranea a la tabla de motos que es de los cliente asi obteniendo una relacion de 1 a muchos un cliente puede tener muchas o una moto.
