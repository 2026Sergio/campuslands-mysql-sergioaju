# README - Ejercicio 003 | GROUP BY

## Descripción

Este proyecto desarrolla una base de datos en **MySQL** para administrar un inventario de skins de un videojuego shooter. La información se almacena en una tabla que permite clasificar las skins por arma, rareza y estado, facilitando la generación de reportes mediante **GROUP BY**.

## Archivos

* **schema.sql:** creación de la base de datos y la tabla.
* **inserts.sql:** carga de datos de prueba.
* **consultas.sql:** consultas utilizando **GROUP BY** y funciones de agregación.

## Objetivo

Aplicar **GROUP BY** para agrupar registros y obtener métricas del inventario mediante consultas orientadas al análisis de datos.

## Competencias desarrolladas

* Diseño básico de tablas en MySQL.
* Organización de datos mediante categorías.
* Uso de **GROUP BY** con funciones de agregación como **COUNT()**, **SUM()**, **AVG()**, **MAX()** y **MIN()**.
* Elaboración de reportes con filtros y ordenamientos utilizando **ORDER BY**.

## Ejecución

1. Ejecutar `schema.sql`.
2. Ejecutar `inserts.sql`.
3. Ejecutar `consultas.sql`.

## Resultado esperado

La base de datos debe ejecutarse correctamente en **MySQL** y generar reportes que agrupen la información del inventario, demostrando el uso adecuado de **GROUP BY** en un escenario de nivel intermedio.
