# Ejercicio 003 - GROUP BY

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó una única tabla llamada `inventario_skins`.
- Se incorporó el campo `categoria` para realizar agrupaciones mediante `GROUP BY`.
- Las consultas utilizan funciones de agregación como `COUNT()`, `AVG()`, `MAX()` y `SUM()` para generar reportes útiles del inventario.
