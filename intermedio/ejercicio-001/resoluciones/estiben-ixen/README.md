# Ejercicio 001 - INNER JOIN

## Descripción

Este proyecto implementa una base de datos relacional en **MySQL** para administrar la información de un torneo de esports MOBA. Se diseñó un modelo compuesto por las tablas **equipos** y **jugadores**, relacionadas mediante una **clave foránea**, permitiendo consultar información utilizando **INNER JOIN**.

## Archivos

* **schema.sql:** crea la base de datos y las tablas.
* **inserts.sql:** inserta los registros de prueba.
* **consultas.sql:** contiene consultas enfocadas en el uso de **INNER JOIN**.

## Objetivo

Aplicar relaciones entre tablas para generar reportes mediante consultas SQL, utilizando filtros, agrupaciones, ordenamientos y funciones de agregación.

## Competencias desarrolladas

* Modelado de bases de datos relacionales.
* Implementación de claves primarias y foráneas.
* Uso de **INNER JOIN** para relacionar información.
* Elaboración de consultas con **WHERE**, **GROUP BY**, **ORDER BY**, **COUNT()**, **AVG()** y **LIMIT**.
* Organización de scripts SQL siguiendo una estructura profesional.

## Ejecución

1. Ejecutar `schema.sql`.
2. Ejecutar `inserts.sql`.
3. Ejecutar `consultas.sql`.

## Resultado esperado

La solución debe ejecutarse correctamente en **MySQL**, conservar la integridad de los datos y generar reportes consistentes que evidencien el uso adecuado de **INNER JOIN** en un escenario de nivel intermedio.
