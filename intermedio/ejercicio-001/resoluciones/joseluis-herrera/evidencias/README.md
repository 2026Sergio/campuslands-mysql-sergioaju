
# Ejercicio-01

# Explicacion
En el siguiente ejercicio se realizó la práctica de creación de bases de datos, estructuración de tablas relacionales y consultas avanzadas utilizando INNER JOIN.
Se creó una base de datos enfocada en deportes electrónicos junto a dos tablas: una tabla de juegos y una tabla de equipos. Se implementó una relación de uno a muchos mediante una llave foránea (id_juego), permitiendo asociar cada equipo a su respectiva disciplina competitiva.
