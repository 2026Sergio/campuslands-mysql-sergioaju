# Ejercicio04

# Taller de motos - SQL

# Descripcion 
En el siguiente ejercicio se realizó la práctica de filtrado avanzado con la cláusula **HAVING** aplicada a una tabla de inventario de un garaje de motos (`motos`). Se implementó la combinación de agrupamientos (`GROUP BY`) con funciones de agregación (`COUNT`, `AVG`) para filtrar grupos completos según condiciones específicas sobre las estadísticas calculadas, diferenciando su uso frente al filtro tradicional `WHERE`.
