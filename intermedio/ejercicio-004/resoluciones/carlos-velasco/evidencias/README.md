# Ejercicio 004 - HAVING

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó una tabla llamada `motos`.
- Las consultas utilizan `GROUP BY` junto con `HAVING` para filtrar resultados obtenidos mediante funciones de agregación.
- Se emplearon funciones como `AVG()`, `COUNT()`, `MAX()` y `SUM()` para construir reportes del garaje.
