# README - Ejercicio 004 | HAVING

## Descripción

Este proyecto implementa una base de datos en **MySQL** para gestionar los servicios de un garaje de motos. La información permite analizar costos, marcas, estados y tipos de servicio mediante consultas que utilizan **GROUP BY** y **HAVING**.

## Archivos

* **schema.sql:** creación de la base de datos y la tabla.
* **inserts.sql:** inserción de registros de prueba.
* **consultas.sql:** consultas utilizando **HAVING**.

## Objetivo

Aplicar **HAVING** para filtrar resultados obtenidos después de realizar agrupaciones, permitiendo generar reportes con criterios específicos sobre los datos del garaje.

## Competencias desarrolladas

* Diseño de tablas en MySQL.
* Uso de **GROUP BY** para agrupar registros.
* Aplicación de **HAVING** para filtrar grupos.
* Empleo de funciones de agregación como **COUNT()**, **SUM()**, **AVG()**, **MAX()** y **MIN()**.
* Elaboración de consultas orientadas al análisis de información.

## Ejecución

1. Ejecutar `schema.sql`.
2. Ejecutar `inserts.sql`.
3. Ejecutar `consultas.sql`.

## Resultado esperado

La solución debe ejecutarse correctamente en **MySQL** y generar reportes agrupados que demuestren el uso adecuado de **HAVING** para filtrar resultados agregados en un escenario de nivel intermedio.
