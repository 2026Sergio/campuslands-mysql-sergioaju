# Guia para maestros

## Revisar PRs

- Confirmar que apunten a `dev`.
- Revisar que la solucion este en `<nivel>/ejercicio-XXX/resoluciones/nombre-apellido/`.
- Rechazar PRs hacia `main`.
- Rechazar entregas que modifiquen enunciados base o respuestas ajenas.

## Feedback

Comentar de forma concreta: que esta bien, que falta y que debe corregir.

## Merge

Solo integrar cuando la estructura sea correcta y no haya conflicto.
