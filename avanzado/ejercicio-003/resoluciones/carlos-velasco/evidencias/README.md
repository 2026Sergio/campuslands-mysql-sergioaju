# Ejercicio 003 - Funciones SQL

## Ejecución

1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.

## Decisiones técnicas

- Se utilizó la base de datos `campuslands_mysql`.
- Se creó una única tabla llamada `inventario_skins`.
- Las consultas demuestran el uso de funciones SQL de texto, numéricas, de fecha y de agregación.
- Se utilizaron funciones como `UPPER()`, `ROUND()`, `LENGTH()`, `DATEDIFF()`, `CURDATE()` y `AVG()` para generar reportes útiles del inventario.
