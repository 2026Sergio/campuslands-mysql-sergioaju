# Resolución Ejercicio 003 (Avanzado) - Funciones SQL Inventario Skins

**Estudiante:** Allison Vargas  
**Nivel:** Avanzado Inicial  

## Descripción
Modelado de un inventario de skins para juego shooter. Incluye la creación de la función almacenada `calcular_valor_mercado` y el uso de funciones nativas (`DATEDIFF`, `UPPER`, `CONCAT`, `CASE`, `ROUND`).

## Estructura
- `ddl/schema.sql`: Estructura de la tabla `inventario_skins` y Stored Function.
- `dml/inserts.sql`: Carga de 8 registros de skins.
- `dql/consultas.sql`: 5 consultas usando la función calculada y funciones escalares/de agregación.
