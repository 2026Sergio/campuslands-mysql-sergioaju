# Ejercicio-3

# Explicacion 
En el siguiente ejercicio se realizó la práctica de funciones almacenadas (`FUNCTION`) y procedimientos avanzados con parámetros (`PROCEDURE`) aplicados a una tabla de inventario de un *shooter* (`catalogo_skins`). Se implementaron rutinas personalizadas para calcular sumatorias con manejo de nulos (`IFNULL`), aplicar actualizaciones masivas basadas en porcentajes y filtrar registros mediante rangos numéricos utilizando operadores como `BETWEEN`.
