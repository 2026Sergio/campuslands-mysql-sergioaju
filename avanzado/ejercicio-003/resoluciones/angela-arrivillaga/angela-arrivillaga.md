# Resolución Ejercicio 003 - Avanzado

## Descripción
Solución al ejercicio 003 sobre un inventario de skins shooter. Se implementan expresiones y cálculos lógicos en SQL para obtener precios promocionales con descuento según la rareza de las armas y categorizar comercialmente los productos.

## Estructura de archivos
* `ddl/schema.sql`: Creación de la base de datos y la tabla `skins`.
* `dml/inserts.sql`: Carga inicial de 8 registros de skins de prueba.
* `dql/consultas.sql`: Consultas con sentencias condicionales (`CASE WHEN`) para reportes y cálculos de precios.

## Pasos para ejecutar
1. Ejecutar `ddl/schema.sql`.
2. Ejecutar `dml/inserts.sql`.
3. Ejecutar `dql/consultas.sql`.
