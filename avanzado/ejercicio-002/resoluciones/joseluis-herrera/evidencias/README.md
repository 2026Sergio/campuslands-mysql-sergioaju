
# Ejercicio-02

# Explicacion 
En el siguiente ejercicio se realizó la práctica de consultas avanzadas utilizando LEFT JOIN en bases de datos relacionales. Se complementó la tabla existente de ranking_royale creando una nueva tabla de patrocinadores, estableciendo una relación donde no todos los registros de la tabla izquierda poseen una coincidencia directa, permitiendo así observar el comportamiento del operador para conservar todos los registros principales e identificar valores nulos (NULL).
